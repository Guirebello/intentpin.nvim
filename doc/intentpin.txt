1. INTRODUCTION                                                   *intentpin*

IntentPin attaches editable notes to visual code selections and exports those
notes as compact change requests for AI coding assistants. Notes are persisted
outside the project and follow edits through extmarks and content re-anchoring.

Requires Neovim >= 0.11.2 and MunifTanjim/nui.nvim.

==============================================================================
2. SETUP                                                    *intentpin-setup*

>lua
  require("intentpin").setup({
    inline = { virtual_text = false, highlight_range = false },
    hover = { mode = "virtual_lines", width = 72 },
    editor = {
      spell = false,
      spelllang = nil,
      diagnostics = false,
      completion = false,
    },
    export = { instruction_language = "en" },
  })
<

See the README for every option and a complete LazyVim plugin specification.
The editor leaves Insert mode with <Esc> or <C-c> and closes explicitly with q
or :q. Spellcheck, diagnostics, and automatic completion are disabled by
default. Set editor.completion to true to preserve the completion behavior
from regular buffers.

==============================================================================
3. COMMANDS                                              *intentpin-commands*

                                                            *:IntentPin-add*
:IntentPin add              Add a note to the last visual selection.

                                                           *:IntentPin-open*
:IntentPin open             Toggle the floating note manager.

                                                           *:IntentPin-show*
:IntentPin show             Focus the note at the cursor in the manager.

                                                           *:IntentPin-edit*
:IntentPin edit             Edit the note at the cursor.

                                                         *:IntentPin-delete*
:IntentPin delete           Delete the note at the cursor after confirmation.

                                                          *:IntentPin-hover*
:IntentPin hover            Highlight the pinned range and show its comment in
                            the configured hover renderer.

Hover modes: "virtual_lines" inserts temporary screen lines without covering
source code; "floating_window" opens a compact popup near the cursor.

                                                         *:IntentPin-expand*
:IntentPin expand {mode}    Show every note in the current file as persistent
                            virtual lines. Modes: show, hide, toggle. The
                            default is toggle.

                                                       *:IntentPin-reanchor*
:IntentPin reanchor         Retry anchors in loaded project files and report
                            how many were checked, recovered, or remain missing.

                                                         *:IntentPin-inline*
:IntentPin inline {mode}    Control persistent gutter signs, virtual text, and
                            range highlights. Modes: show, hide, toggle.

                                                           *:IntentPin-next*
:IntentPin next             Jump to the next note, wrapping at the end.

                                                           *:IntentPin-prev*
:IntentPin prev             Jump to the previous note, wrapping at the start.

                                                           *:IntentPin-copy*
:IntentPin copy {mode}      Copy notes. Modes: checked, checked-absolute, all,
                            all-absolute, current, current-absolute.
                            all-absolute ignores checkboxes and uses full paths.

                                                          *:IntentPin-clear*
:IntentPin clear            Delete every note in the current project.

==============================================================================
4. MANAGER                                              *intentpin-manager*

<CR>       Jump to code                  <Space>  Toggle inclusion
a          Include all                   u        Exclude all
e          Edit                          d        Delete
D          Delete all                    y        Copy current
Y          Copy checked                   gY       Copy checked, absolute paths
A          Copy all                      p        Toggle preview
r          Retry broken anchors          ?        Open persistent help
q/<Esc>    Close

==============================================================================
5. STORAGE                                              *intentpin-storage*

State is stored in:

  stdpath("state")/intentpin/<sha256-project-root>.json

No IntentPin files are written into the project itself.

The instruction prepended to copied notes can be customized with:

>lua
  export = {
    instruction_language = "pt-BR",
  }
<
