## [0.1.0]

### Added

- Persistent notes attached to exact visual code selections.
- JSON storage outside source repositories with atomic writes.
- Extmark tracking and context-aware re-anchoring for moved code.
- Orphan warnings in the gutter, manager, and preview.
- Virtual-line and floating-window hover renderers.
- Persistent expanded-file view using virtual lines.
- Floating note manager with preview, editing, inclusion controls, navigation, deletion, and exports.
- Persistent, scrollable manager help.
- Relative and absolute-path exports with English, Portuguese, Spanish, and custom instructions.
- Configurable inline signs, virtual text, range highlights, spellcheck, diagnostics, completion, borders, and layout sizes.
- `:checkhealth intentpin` integration.
- Headless test suite covering the core workflow and UI state.
